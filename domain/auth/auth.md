# 认证领域

实现用户登录、注册、检入以及登出功能，并存储会话信息和颁发 JWT 令牌的领域。

## 上游 - AuthApplication

1. 登录 SignIn
    - 通过 Email 查找用户记录
    - 比对用户密码是否相同
    - 创建 JWT 令牌
    - 创建会话
    - 返回 JWT 令牌

2. 注册 SignUp
    - 通过 Email 查找用户记录
    - 判断用户是否存在
      - 是：返回用户已存在
      - 否：创建用户
        - 密码加密
        - 创建用户：用户数据落库
    - 返回

3. 检入 CheckIn
    - 解析 JWT 令牌
    - 通过 JWT 令牌和用户 ID 查找会话
      - 会话存在：
        - 查找最新的用户信息
        - 构建新的 JWT 令牌
        - 更新会话中的 Token 字段
      - 会话不存在：
        - 返回 JWT 令牌无效错误
    - 返回

4. 登出 SignOut
    - 解析 JWT 令牌
    - 通过 JWT 令牌和用户 ID 删除会话
    - 返回

5. 验证 Validate
    - 解析 JWT 令牌
    - 通过 JWT 令牌和用户 ID 验证会话
    - 删除会话

## 实体 / 值对象

1. 用户实体 userEntity
    - 用户 ID
    - 用户账户
    - 用户邮箱
    - 用户密码
    - 用户昵称
    - 判断当前用户 ID 是否有效：用户 ID 是否大于 0
    - 判断当前用户昵称是否有效：用户昵称长度是否在 2 到 20 个字符之间
    - **判断当前用户实体是否有效**：判断当前用户 ID 是否有效 + 判断当前用户昵称是否有效
    - 用户密码加密：加密后修改用户密码值

2. 会话实体 sessionEntity
    - 会话 ID
    - 用户 ID
    - 会话 Token
    - 重新登录时间
    - 登录设备类型
    - 判断当前会话实体是否有效：会话 ID 是否大于 0
    - 判断当前会话是否在重新登录时间之后：会话重新登录时间是否在当前时间之后
    - **判断当前会话是否有效**：判断当前会话实体是否有效 + 判断当前会话是否在重新登录时间之后

3. JWT 载荷 jwtClaimsVO
    - 用户 ID
    - 用户账户
    - 过期偏移时间
    - 签发者
    - 签发地

## 仓库

仓库层接口函数必须收敛参数。

### 用户仓库 userRepository

1. 创建用户
2. 通过 Email 查找用户记录
3. 通过用户 ID 查找用户记录
4. 用户密码对比

### 会话仓库 sessionRepository

1. 创建会话
2. 通过 JWT 令牌和用户 ID 查找会话
3. 依据用户 ID 更新会话 Token 字段
4. 通过 JWT 令牌和用户 ID 删除会话

### JWT 仓库 jwtRepository

1. 创建 JWT
2. 验证 JWT
3. 解析 JWT
