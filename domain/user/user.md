# 认证领域

实现用户登录、注册、检入以及登出功能，并存储会话信息和颁发 JWT 令牌的领域。

## 上游 - 认证 Service

1. 更新昵称 UpdateNickname

2. 更新头像 UpdateAvatar

## 限界上下文

1. 更新昵称
2. 创建用户
3. 删除（注销）用户
4. 修改用户密码

## 实体 / 值对象

1. 用户实体 userEntity
    - 用户 ID
    - 用户账户
    - 用户邮箱
    - 用户密码
    - 用户昵称
    - 用户头像
    - 用户角色
    - 用户状态
    - 用户描述
    - 用户配置 | userConfigVO
    - 创建时间
    - 更新时间
    - 判断当前用户 ID 是否有效：用户 ID 是否大于 0
    - 判断当前用户昵称是否有效：用户昵称长度是否在 2 到 20 个字符之间
    - **判断当前用户实体是否有效**：判断当前用户 ID 是否有效 + 判断当前用户昵称是否有效

2. 用户配置 userConfigVO
    - 用户配置 ID
    - 用户 ID
    - 主题
    - 其他...
