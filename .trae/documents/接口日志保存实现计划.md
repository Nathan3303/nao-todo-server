# 接口日志保存实现计划

## 项目分析

这是一个基于 Gin 框架的 Go 项目，具有分层架构设计，使用 logrus 作为日志库。需要为所有接口添加本地日志功能。

## 实现目标

1. 为所有接口添加统一的请求/响应日志记录
2. 记录关键信息：请求时间、方法、路径、状态码、响应时间、客户端信息等
3. 支持日志分级（INFO、ERROR、WARNING等）
4. 实现日志文件按日期滚动分割
5. 配置日志输出格式（JSON格式）
6. 确保日志不影响接口性能

## 详细设计方案

### 日志配置结构体

```go
type LogConfig struct {
    Level         string `yaml:"level"`         // 日志级别：debug, info, warn, error, fatal, panic
    FilePath      string `yaml:"filePath"`      // 日志文件路径
    MaxSize       int    `yaml:"maxSize"`       // 单个日志文件最大大小（MB）
    MaxAge        int    `yaml:"maxAge"`        // 日志文件保留天数
    MaxBackups    int    `yaml:"maxBackups"`    // 保留的日志文件副本数量
    Compress      bool   `yaml:"compress"`      // 是否压缩日志文件
    OutputConsole bool   `yaml:"outputConsole"` // 是否同时输出到控制台
}
```

### 日志中间件设计

```go
func RequestLogger() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 记录请求信息
        start := time.Now()
        
        // 继续处理请求
        c.Next()
        
        // 记录响应信息
        duration := time.Since(start)
        
        // 记录日志
        logrus.WithFields(logrus.Fields{
            "method":     c.Request.Method,
            "path":       c.Request.URL.Path,
            "status":     c.Writer.Status(),
            "duration":   duration,
            "ip":         c.ClientIP(),
            "user_agent": c.Request.UserAgent(),
            // 可以添加更多字段
        }).Info("API 请求完成")
    }
}
```

### 日志输出格式

使用 JSON 格式输出，便于日志分析：

```json
{
  "time": "2026-04-12T10:00:00Z",
  "level": "info",
  "msg": "API 请求完成",
  "method": "POST",
  "path": "/api/auth/signin",
  "status": 200,
  "duration": "123.45ms",
  "ip": "192.168.1.100",
  "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
}
```

## 验收标准

1. 所有接口都有统一的请求/响应日志
2. 日志包含关键信息：时间、方法、路径、状态码、响应时间、客户端IP、设备类型
3. 日志文件按日期正确滚动
4. 日志支持分级记录
5. 控制台输出和文件输出同时工作
6. 日志记录不影响接口性能
7. 所有代码符合项目架构风格

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 性能影响 | 高并发下可能影响接口响应 | 使用异步日志记录、控制日志级别 |
| 磁盘空间 | 日志文件过大可能占满磁盘 | 合理配置日志滚动策略 |
| 敏感数据 | 可能记录敏感信息 | 过滤敏感字段、配置日志内容 |
