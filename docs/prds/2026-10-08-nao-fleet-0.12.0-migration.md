## 0. 背景

上游 nao-skills 发布 **v0.12.0**：机制从「项目内铺开整套 `.agents/`」改为 **一个 pi 包 + 项目内单个入口 shim**（ADR `nao-skills/docs/adr/2026-10-08-nao-skills-single-skill-pi-package.md`）。
本项目当前是 **0.11.0 本地全量副本**（`.agents/.nao-version` = `0.11.0`，`.agents/` 入库 43 个文件）。

上游已**退役**旧完整性判据（「项目内 `.agents/**` 与上游逐字节 sha 一致」不再适用）⇒ 本项目现状是**有机制、但没有验证手段**。同形态迁移已在 `nao-todo`（T506）跑通并归档，本仓是既定路线 A 的第二个批次。

## 1. 问题证据

| 机制形态陈旧 | `.agents/` 顶层 **8 项**（`checklists` `common` `.nao-version` `prompts` `roles.yaml` `scripts` `skills` `templates`，实测）+ `nao-fleet.sh` 全量副本（0.11.0 与上游 tag `v0.11.0` 逐字节一致）                                                          |
| 无验证手段   | 上游 README 声明 sha 判据自 0.12 起失效                                                                                                          |
| 项目侧引用面 | **`.agents/` 之外 0 处**（实测：`AGENTS.md` / `CLAUDE.md` / `README.md` / `docs/**` / `.github/workflows/**` 对 `.agents`、`nao-fleet`、`NAO_SKILLS` **0 命中**） |
| 无 CI 耦合   | `ci.yml`（build/vet/unit/gofmt/golangci-lint + 集成）**0 命中** `.agents` / `nao-fleet`                                                            |
| 迁移成本     | **最低**（同形态中最省：无文档改写、无 lock 去重、无 `devEngines` 阻断）                                                                          |
