# 用户领域

实现用户信息获取、信息修改、头像上传、密码修改以及注销等操作。

## 上游 - 用户 Service

1. 更新昵称 UpdateNickname
    - 获取用户 ID
    - 调用域函数 - 更新用户昵称
    - 返回结果

2. 获取用户信息 GetProfile
    - 获取用户 ID
    - 调用域函数 - 通过用户 ID 获取用户记录
    - 构建返回结果
    - 返回结果

3. 更新密码 UpdatePassword
    - 获取用户 ID
    - 调用域函数 - 更新用户密码
    - 返回结果

4. 更新头像 UpdateAvatar
    - 获取用户 ID
    - 调用域函数 - 更新用户头像
    - 返回结果

5. 更新用户头像文件 UpdateAvatarByFile
    - 获取用户 ID
    - 获取文件
    - 验证文件大小和类型
    - 生成唯一文件名
    - 确保目录存在
    - 保存文件
    - 调用域函数 - 更新用户头像
    - 返回结果

    - 创建时间
    - 更新时间
    - 判断当前用户 ID 是否有效：用户 ID 是否大于 0
